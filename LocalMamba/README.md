# LocalMamba

## Problem 
本文对研究背景现状的介绍是这样子的：1，传统vit因为其时间复杂度达到了o(N²)，所以其计算开销大，难以处理高分辨率图像。2，Mamba采用SSM结构，时间复杂度低，能高效处理长距离序列。但是其一维扫描的特性在图像处理上面会破坏图片的二维结构（这两点在我之前做的VeMamba过程当中也意识到了这些并且理解了） 

所以LocalMamba所要解决的真正问题是，在面对序列的状态转换和空间结构化的视觉表征的不匹配前提下，怎么保持局部依赖关系，从而辅助视觉Mamba模型来识别局部纹理

## Core Insight 
1，对于解决这个问题，LocalMamba给出的解答是引入一个局部的扫描窗口，但是和CNN卷积不同的是,卷积的窗口会存在窗口之间的重叠，而他这里划分出来的所有扫描窗口是互相不重叠的。 将一张可能是256x256的原始图像分割成数个2x2，7x7的小模块，然后对这些小模块独立的去做Vmamba的扫描功能。（单论这一块其实也没有很创新的地方，我自我感觉跟我自己提出来的ASM的效果各有优劣之处）

2，但是重要的一点在这里，他的扫描机制不是完全照搬的VMamba把一个窗口复制成四份然后同时进行四种方向的扫描再融合，他做的是让模型自己去识别在SSM的哪一层使用哪些扫描方式会更好。这点确实是很有创新的地方，因为本身Mamba在不同层数的时候其特征就有所区别。 
 
## Why It Matters 
至于为什么这个方法能够奏效？就我自己的理解来看，当你仅对一个很小的窗口进行展开扫描，其展开的序列里面就有的局部信息占比就很大了。所以Mamba在这里就能够更好的聚焦到局部信息里去。 
 
## Key Contributions 
- 将局部空间连续性重新引入 Vision Mamba 
- 提出局部扫描路径以保持相邻依赖关系 
- 引入跨层的扫描方向搜索 
- 结合局部和全局标记遍历策略 
- 表明扫描策略本身是一个重要的架构因素 
 
## Personal Observation 
就我个人阅读完这一篇文献而言，单纯通过Mamba的高效序列建模是做不到非常好的视觉理解的。要想发挥好Mamba的长序列高效计算优势，一个很可能的方向就是要重点聚焦到我们是用什么方式来排列和聚焦信息的。如何为Mamba 提供一个有效的data flow是我们的主要攻坚点。
